# Case Study: Payment Gateway Platform

**Type:** FinTech / Payment Gateway  
**Company:** Hsblco Solution  
**Duration:** ~1 Year  
**Role:** Primary Implementation Engineer  
**Status:** Production (US client)

---

## Overview

A US-based client owned multiple businesses and websites, each using different payment solutions. They needed a centralized payment gateway to unify transaction workflows across all businesses, connected to US banking/payment APIs.

I was the primary implementation engineer — translating business workflow into a production Laravel application.

---

## My Responsibilities

- Full Laravel application development from provided business workflow
- Database design (users, transactions, payments, business operations)
- Admin panel and customer-facing functionality
- REST API development for payment workflows
- Banking/payment API integration
- Authentication, authorization, and role-based access control
- Reporting dashboards and transaction management
